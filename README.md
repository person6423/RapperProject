# RapperProject

Expanded from an older version made in TurboWarp, RapperProject is a heavily inspired [PaRappa The Rapper](https://en.wikipedia.org/wiki/PaRappa_the_Rapper) engine made in [Love2D](https://love2d.org/), which is a simple, easy to use framework coded in Lua.

> [!IMPORTANT]
> RapperProject is in a diabolically early stage, basically missing out on everything.
> Be cautious for bugs and other unexpected mishaps, feel free to open Issues if you like (high chance these bugs will be fixed anyway)

This README will be expanded with more information later on in development.  
As RapperProject, in it's current stage, is practically nothing, there is literally nothing to write about here :P
